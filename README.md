# 🧮 Python GUI Calculator

A basic calculator application built using **Python and Tkinter** with a custom-designed graphical user interface.

## ✨ Features
- Basic arithmetic operations (+, -, *, /)
- Parentheses support
- Decimal number calculations
- Clear (C) functionality
- Custom button styling and dark-themed interface
- Compact, fixed-size calculator window

## 🛠️ Technologies Used
- Python
- Tkinter
- ttk (Themed Tkinter Widgets)

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/dakshesh-tech/python-gui-calculator.git
   ```

2. Navigate to the project directory:
   ```bash
   cd python-gui-calculator
   ```

3. Run the application:
   ```bash
   python Calculator.py
   ```
